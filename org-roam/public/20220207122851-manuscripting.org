#+title: manuscripting

Manuscripting is my workflow for producing [data]
narratives.  Data narratives is an abstract term that can
refer to scientific articles, white papers, kaggle
notebooks, etc.... These documents can be large and complex
given the burden for knowledge gathering and citation and
the burden for presenting large amounts of data
effiently. This node will be concerned mainly with the
system of tools which supports the construction of these
documents.

Concerns
- exploring available literature
- capturing 'references' to relevant pieces of literature
- managing and exploring these references efficiently
- optionally treating references them as top level nodes in org-roam
- methods for inserting citations and constructing bibliographies

* Components
- [[id:D975F550-E5CC-4074-9D60-9D38C62BBB66][org-roam]] for knowledge graphing
- [[id:6C4CA3C9-C448-471C-8CA3-E4F29E4F3D7C][biblio]] for cataloguing records
- [[id:288895DE-319D-4ADE-BC73-F4384F258FF0][BibTeX]] for cataloguing and managing references
- [[id:AB6E4C1D-7790-4EA9-9B9C-553791AE58B6][org-ref]] for inserting citations to references and working
  witht he citations
- ivy-bibtex as a completion ui to references and relevant
  info (not consult yet)
- [[id:46C0ABDC-3DBC-46D6-80F2-9E1FCBDFD5F4][org-roam-bibtex]] (orb) provides integrattiono between org
  roam and citation management software

* Important functions
- biblio-*, provides ways to 
- pubmed - search dois 
- doi-add-bibtex-entry: adds bibtex entry given doi
- orb-note-actions
- org-ref-insert-link

* Usage
- PDFs: although automated location and download of PDF
  files is possible, we shouldn't use this as it rarely
  works.  This process will still be driven by the browser,
  but we will load PDFs into the knowledge graph from within
  Emacs usinig orb-note-actions, ivy-bibtex, or
  consult-bibtex.
