#+title: Resource Description Framework
From wikipedia: "RDF is a directed graph composed of triple
statements. An RDF graph statement is represented by: 1) a
node for the subject, 2) an arc that goes from a subject to
an object for the predicate and 3) a node for the
object. Each of the three parts of the statement can be
identified by a URI."
